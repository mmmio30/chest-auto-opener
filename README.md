# 宝箱オート開封ツール

ブラウザゲームを複数窓（既定3窓）で開いた状態で、各窓について

1. **前準備クリック**（宝箱タブの有効化・窓のフォーカス。既定3回、増減可）
2. **コモン宝箱** 開く → 閉じる
3. **レア宝箱** 開く → 閉じる
4. **イモータル宝箱** 開く → 閉じる

の順にクリックし、1サイクル終わったら指定秒（既定60秒）待って永久に繰り返します。

クリック座標はすべて**ティーチング（F8で今のマウス位置を取り込む）**で設定できます。

---

## 1. 準備

```
pip install -r requirements.txt
```

（`pyautogui` と `pynput` が入ります）

## 2. 起動

`起動.bat` をダブルクリック。もしくは

```
python chest_auto.py
```

## 3. ティーチング（座標の教え込み）

1. ゲームの3窓を、いつも使う位置・サイズに並べておく
2. ツールの **「全窓を順にティーチング」** を押す
3. 画面下のステータスバーに
   `[ティーチング 1/27] ★ 窓1 / 前準備 / 宝箱タブ1 ★ にマウスを合わせて F8`
   と出るので、**その場所にマウスカーソルを置いて F8 キー**を押す
4. 次の対象に自動で進むので、27点ぶん繰り返す

取り込む順番（1窓あたり9点 × 3窓 = 27点）：

| # | 対象 | 置く場所の例 |
|---|------|--------------|
| 1 | 前準備 / 宝箱タブ1 | 宝箱タブを有効化するための1回目のクリック位置 |
| 2 | 前準備 / 宝箱タブ2 | 2回目のクリック位置 |
| 3 | 前準備 / 宝箱タブ3 | 3回目のクリック位置（同じ場所を複数回押す場合は同じ座標でOK） |
| 4 | コモン宝箱 / 開く | コモン宝箱の「まとめて」ボタン |
| 5 | コモン宝箱 / 閉じる | 開封結果ダイアログの閉じる場所 |
| 6 | レア宝箱 / 開く | レア宝箱の「まとめて」ボタン |
| 7 | レア宝箱 / 閉じる | 閉じる場所 |
| 8 | イモータル宝箱 / 開く | イモータル宝箱の「まとめて」ボタン |
| 9 | イモータル宝箱 / 閉じる | 閉じる場所 |

> **スキップしたい点**は F8 を押さず「ティーチング中止」で抜けて、
> その点の行の「取得(F8)」から個別に設定するか、空のままにします。
> 空のままの点は実行時に自動で飛ばされます。

### 前準備クリックについて

**宝箱を開く前に宝箱タブ自体を有効化する必要がある**ケース用の枠です。
毎サイクル、その窓の宝箱クリックより前に、上から順に実行されます。

- 既定は **3回**。回数を変えたいときは **「＋ステップ追加」/「削除」** で増減できます
- 同じ場所を複数回押すだけなら、同じ座標をティーチングすればOKです
- 1クリックごとに **「後の待ち(秒)」** を設定できるので、タブの切り替え演出が長い場合は伸ばしてください
- その窓では不要なら **「毎サイクル、宝箱の前にこれを押す」のチェックを外す**と丸ごと飛ばせます
- **「前準備だけティーチング」** ボタンで、この3点だけを取り直せます

取り込んだ座標は押した瞬間に `chest_config.json` へ自動保存されます。

### 楽をする方法：窓間コピー

3窓が**同じサイズで横に並んでいる**なら、窓1だけティーチングして、
窓2・窓3のタブで「他の窓から座標をコピー」を使うと一発です。

- コピー元 = 窓1
- dX = 窓1個ぶんの横幅（既定で `画面幅 ÷ 窓数` が入っています。写真の環境なら約 1279）
- dY = 0

→「コピー実行」。ズレていたら各行の「テスト」で確認しながら微調整してください。

## 4. 実行

- **▶ 開始 (F9)** … 1サイクル実行 → 周期秒待つ → を無限に繰り返し
- **■ 停止 (F12)** … 停止
- **1サイクルだけ実行** … 動作確認用
- **テスト**（各行） … 2秒後にその1点だけクリック。座標が合っているかの確認に

実行中はマウスを触らないでください（カーソルを乗っ取ります）。

## 5. 止め方（3通り）

| 方法 | 説明 |
|------|------|
| **F12** | どのウィンドウが前面でも効く緊急停止 |
| **F9** | 開始/停止のトグル |
| **マウスを画面の左上角へ勢いよく飛ばす** | pyautogui のフェイルセーフ。暴走時の最終手段 |

## 6. 設定項目

| 項目 | 意味 | 既定 |
|------|------|------|
| 繰り返し周期(秒) | サイクル開始から次のサイクル開始までの間隔 | 60 |
| マウス移動(秒) | 座標へ移動するのにかける時間。0にすると瞬間移動 | 0.15 |
| クリック前待ち(秒) | 移動してからクリックするまでの待ち | 0.15 |
| 後の待ち(秒)（各ステップ） | そのクリックの後に待つ時間。演出が長い箱は伸ばす | 前準備0.5/0.5/0.8・開く1.0・閉じる0.6 |
| 終了後マウスを元に戻す | 1サイクル終了後、開始前のカーソル位置へ戻す | ON |
| 窓数 | 1〜8。増やすとタブが増える | 3 |

### ステップは増やせます

「開く → 受け取る → 閉じる」のように**閉じるまでに複数クリックが要る**場合は、
その宝箱の **「＋ステップ追加」** で3つ目以降のクリックを足せます。
ステップ名（`開く` などの入力欄）は自由に変更できます。

## 7. 設定ファイル

`chest_config.json` に保存されます。ウィンドウを閉じるときにも自動保存。
**アプリ起動中にこのファイルを直接書き換えても、アプリ側の保存で上書きされます**（変更したいときは一度アプリを閉じてから編集してください）。
別の窓配置（例：ノートPC用）を使い分けたい場合は、このファイルをコピーして
リネームしておき、「読込」ボタンで切り替えてください。

## 8. 注意 / トラブルシューティング

- **座標がズレる**：Windowsの拡大率が100%以外でも合うようDPI対応済みですが、
  **ブラウザのズーム倍率や窓の位置・サイズを変えると全部ズレます**。
  変えたら必ずティーチングし直してください。
- **クリックが効かない**：ブラウザが背面にあると1回目のクリックが
  「窓をアクティブにするだけ」で消費されることがあります。
  **前準備クリック**にステップを1つ足し、先頭でその窓の空白部分を押すようにしてください。
- **ダイアログが閉じない**：`後の待ち(秒)` が短すぎて演出中にクリックしている可能性大。
  開くステップの待ちを 1.5〜2.5 秒くらいに伸ばしてみてください。
- **管理者権限**：通常は不要です。ブラウザを管理者権限で起動している場合のみ、
  本ツールも管理者権限で起動しないと入力が届きません。
- ゲーム側の利用規約で自動操作が禁止されていないか、念のためご確認ください。
